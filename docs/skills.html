六套 Images 2.5 Skill

从社区案例抽象出来的可抄流程——不是插件，而是一键复制成 Agent Skill（Cursor / Codex / Grok Bot 的 SKILL.md）。也可当人类清单在 ChatGPT Images 里逐步跑。

怎么用（给 Agent / 给人）

  1. Skill = 可给 Agent 复用的配方（标准 SKILL.md），同时也是人类 checklist——不是要安装的插件。
  2. 点每张卡的「复制给 Agent（SKILL.md）」→ 粘贴到 Cursor Skills / Codex skill / 任意 agent 的 skill 文件夹，保存为 SKILL.md。
  3. 或者打开查看 SKILL.md（仓库 skills/<id>/SKILL.md），也可直接 clone 整个 skills/ 文件夹。
  4. 仍然可以不复制、纯手动：打开 ChatGPT → 图像 / Images，按步骤在网页版跑（Sketch / Templates / 标注精修仅网页版）。
  5. Flare 先草稿，Sunburst 出终稿（赶量用 Flare，抠字/细节用 Sunburst）。有 playbook 的卡可点进去拿长提示词。

## 这篇在讲什么

用 Images 2.5 从零搭一套可复用的虚拟人物资产：文生主体人像 → 五视图身份锚点 → 表情/头像/表情包 → 纸片拼贴封面与公众号头图 → 正文观点配图 → 换装街拍九宫格 → PV 九宫格分镜 + MiniMax H3 15 秒视频。自媒体/品牌一人团队可直接抄提示词落地。

## 流程总览

1. **01 生成人物形象** — 文生主体人像 + 五视图 / model sheet
2. **02 自媒体应用** — 表情九宫格、账号头像、卡通/像素头像、表情包六格
3. **03 做封面** — 3:4 竖版封面 + 公众号横版拼贴风头图
4. **04 文章配图** — 折页比喻 + 参考分工拼贴
5. **05 换装街拍电商** — 咖啡店九宫格换装 + 包一致性
6. **06 PV 九宫格 + 视频** — 分镜九宫格 → MiniMax H3 15 秒提示词
7. **07 写在最后** — 串成流水线、举一反三的方法论

做成有设计感的短篇PV：开头建立欲望，中段连续三个“不会”加速施压，“费时费力／出片率低”形成重拍；拿起模型时放慢半拍，再进入机甲幻想高潮，最后收回现实。切点跟随音乐重音，镜头有快慢变化与短暂停留。运镜必须产生前景、人物、背景之间的真实视差，不把静态整图简单放大平移。
【AE质感的文字动效】
把每个关键词当作独立、字形固定的平面图形层，使用类似After Effects精修的关键帧动画：快速启动、平滑减速，位置与缩放协同变化，配合方向一致的短运动模糊；文字落定后立刻清晰。
每组大字约0.25—0.4秒完成入场，词组之间错开约0.04—0.08秒，落定后至少保留0.5秒清楚阅读。主要使用遮罩揭示、分词错帧滑入、实字与轮廓字视差、轻微缩放回落。少数重点字允许一次极轻的过冲回正，幅度约2%—3%，不要弹簧反复震荡。
文字可分布在人物前后，经过人物轮廓时遮挡边缘干净；主体动、镜头动时，文字保持明确的屏幕阅读位置。只让整字或词组移动，不让笔画液化、拆散、重绘、闪烁。保留参考中的粗字、白字、电蓝重点词与构图层级。

0.00—1.50秒｜AI短剧
从桌面前景快速但平滑地推近女孩持笔思考的中景，前景模型掠过画面边缘，最后减速停住。巨大白色“AI”从左侧遮罩揭示，蓝色“短剧”晚0.06秒从下方滑入，轻微缩放回落。镜头以笔尖下落结束。
1.50—2.75秒｜不会写剧本
顺着落笔动作匹配切到微俯拍，镜头沿纸页小幅向右滑，女孩写两笔后停住。“不会”先落定，“写剧本”分词错帧向上进入，“写”为蓝色重音。桌面与手保持稳定，不变形。
2.75—4.00秒｜不会搭场景
切到侧面中景，镜头沿女孩肩膀小幅弧线移动，露出显示器内未完成的机库，她托腮看屏幕。“不会搭”横向揭示，“场景”从下方快速上移并柔和减速；文字运动方向延续前一镜。
4.00—5.25秒｜不会拆分镜
女孩举起分镜纸，纸边短暂遮挡镜头，顺势切入更近的正面视角，镜头轻推。左侧“不会／拆／分镜”自上而下错帧出现，蓝色“拆”轻微过冲后一次回正。纸页不盖住人物整张脸。
5.25—6.50秒｜费时费力
切到扶额近景，镜头缓慢下压并靠近，女孩放下笔。“费时”从左上、“费力”从右下沿对角线滑入，在重拍处同时落定；入场模糊迅速消退，形成短暂的压迫停顿。
6.50—7.75秒｜出片率低
切到越肩视角，沿鼠标到屏幕的方向快速推近并减速，女孩的手停在鼠标上。实心蓝字“出片率低”横向进入，同句轮廓字延迟0.08秒、以更小位移跟进，构成有层次的拖随效果，落定后不继续晃动。
7.75—10.00秒｜机甲迷
女孩双手捧起同一机甲模型，镜头由手中模型缓缓抬向她专注的脸，并做小幅侧移，台灯暖白光照亮脸与模型。“机甲”白字柔和滑入，蓝色“迷”从略小放大到正常尺寸，平滑停住。这里给表情和模型留出呼吸，结尾视线回到蓝色胸核。
10.00—13.00秒｜想做机甲漫剧
用模型蓝色胸核做形状与光色匹配剪辑，进入她想象中的巨大机甲机库。低机位向前推进并逐渐仰起，女孩保持右下方背影，机甲通过缓慢机械动作、胸核亮度与少量蒸汽体现体量。“想做／机甲／漫剧”按层次错帧展开，“机甲”蓝字最大，随镜头形成轻微前后景视差。12.40秒后减慢运镜，让高潮完整停留，避免频繁甩镜。
13.00—15.00秒｜一直没实施

## 07 写在最后

# Image 2.5：可控性从提示语迁到交互

> 来源：[卡尔的AI沃茨 · 微信公众号](https://mp.weixin.qq.com/s/-_pJRujQA4xHC2H8B6XWtA) · 整理进 awesome-gpt-image2.5 便于对照选型  
> 分类：选型评测 · 非可复用 Skill（综述 + bakeoff）

## 这篇在讲什么

OpenAI 突然上线 Image 2.5：更快、更清晰、多轮编辑更稳，并新增涂鸦（Sketch）、Templates、标注精修。API 侧同步放出 **Flare**（中杯：同款质量约 +50% 速度）与 **Sunburst**（超大杯：更高精度、更慢）。作者用 logo / 角色 / 定格 / 建筑 / 风格 / 画幅做 2 vs 2.5 对照，并给出「是否已切到 2.5」的透明底自测。核心论点：**可控性正从「把约束写进提示语」迁到「用交互直觉操作」**；复杂场景下精确文字仍不可替代。

## 新功能速览

| 能力 | 要点 |
| --- | --- |
| 生成质量 | 更快、更高清；多轮编辑一致性更好（作者：以前 Image 2 改五轮就常重抽） |
| 标注精修 | 点选不满意的局部精确修改（例：角色右眼下方点痣一次成功） |
| 涂鸦 / Sketch | 在画布上写写画画，模型参考画面信息生成；画板内文字更像补充说明而非必须原样保留 |
| Templates | 网页版入口：左下角「+」→ 创建图片；对话里直接打「海报/logo」不会唤出模版 |
| Flare | API 中杯：质量对齐 2.5，处理速度约 +50% |
| Sunburst | API 超大杯：更高生成精度，耗时更长 |
| 一致性 | 同蓝立方体约 150 次生成，2.5 形变明显更少；稳定性约束不必再全塞进提示语 |

### 15 个 Templates（第一批）

海报、室内设计、Logo、插画、头像照、图标、产品图、周边、信息图、宣传单、书籍封面、App样机图、包装设计、广告图、视频封面。

切换模版会在对话开头注入不同提示语，生成过程也会给出比无模版时更详细的配置方案。

### 使用坑：Codex vs ChatGPT 网页

- **Sketch / Templates 目前请用 ChatGPT 网页版。** 作者在 Codex 反复 `@Sketch`、更新与重启均未生效。
- 滚动上线策略下，需要可靠方式判断当前是 Image 2 还是 2.5（见下节透明底自测）。

## 透明底自测（判断是否已是 2.5）

Image 2 通常无法直接生成**原生**透明背景；2.5 明确补上了该能力。可用下列提示自测（原文提示词，请原样使用）：

```
用 $imagegen 生成一张 1024x1024 PNG：一只白色杯子，纯透明背景，不要绿幕/抠图，不要白底。生成后告诉我：1) 是否原生 transparent2) 文件路径
```

判定：若输出为原生 transparent PNG（非绿幕/抠图/假白底），更可能已走到 Image 2.5。

## 2 vs 2.5 实测结论（作者对照）

| 题材 | 观察 |
| --- | --- |
| Logo | 构图差别不大；**清晰度**上 2.5 拉开距离；基于 logo 做周边也可行 |
| 人物 / 角色设定图 | 细节与文字可读性更好；标注点痣一次成功 |
| 定格动画 | 最能看出前后帧物体形变；2.5 一致性「非常带劲」（例：鹈鹕/鳄鱼骑单车定格） |
| 建筑 | 沿用公开提示语左右对照（文中展示） |
| 风格迁移 | 作者反而觉得 **2.5 风格化略逊于 2**，更偏柔和 |
| 画幅控制 | 1:1、3:4、4:3、9:16、16:9、21:9 封面元素控制对 2.5「简简单单」 |

另：分享成片时可带提示语；OpenAI 会把提示拆成 case / 风格 / 场景等模版化结构。

## 交互迁移论点（摘录）

> 涂鸦让你用画的替代用写的，模版让你跳过从零构建提示语的过程，标注精修让我们用点点替代文字描述，一致性的提升意味着我们不用再往提示语里塞各种稳定性约束。  
> 每一个新功能都在做同一件事：把原来需要写进提示语里的东西，变成更直觉的操作。  
> 提示语当然还有用，复杂场景下精确的文字描述仍然不可替代。但对大多数人来说，好的提示语不再是用好 AI 生图的前提条件了。

六套 Images 2.5 Skill

从社区案例抽象出来的可抄流程——不是插件，不用安装。先看下面「怎么用」，再按场景选一条在 ChatGPT Images 里跑。

怎么用（30 秒上手）

  1. 这不是要安装的插件——这里的 Skill = 可抄工作流清单（步骤 + 注意点），在 ChatGPT Images 2.5 里按步骤做就行。
  2. 先选场景：下面六张卡看「何时用」，对上你的任务再点开。
  3. 打开 ChatGPT → 图像 / Images（网页版才有 Sketch / Templates / 标注精修；别指望 Codex 里 @Sketch）。
  4. 从上到下照着步骤跑：需要控形用 @Sketch；要模板点「创建图片」选 Templates；改局部用圈选/评论，别整段重抽。
  5. Flare 先草稿，Sunburst 出终稿（赶量用 Flare，抠字/细节用 Sunburst）。
  6. 有「完整 playbook」的卡，点进去复制长提示词；没有的就按步骤用自己的素材跑一遍。

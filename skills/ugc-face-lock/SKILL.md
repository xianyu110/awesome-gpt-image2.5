# Images 2.5 · UGC 写真锁脸配方

## When
用户要做广告/种草人像、UGC 写真，或抱怨「假色假噪点假皮肤」。

## Steps
1. 准备 **1 张干净参考脸**（遮挡少、光线清楚）+ **1 张真照片**作颗粒/色调参考（可选）。
2. Prompt 结构：用途 → 可见细节 → 姿态/视线 → 服装分块（可互换）→ 画幅 → 必须保留的脸部特征。
3. 先 Flare 出 2–4 张锁脸草稿；只用评论/标注改妆发服装，避免重抽丢一致性。
4. 终稿 Sunburst；检查皮肤纹理、噪点、色温是否像「偷来的真照片」而不是塑料感。
5. 交付：成片 + 服装可替换段落（上衣/下装/鞋可拆换）。

## Anti-patterns
- 无参考硬生成真人广告脸。
- 一次改动作+发色+妆容导致脑补遮挡区。

## Notes
参考 awesome：写真 UGC 颗粒锁脸、可互换衣装 Prompt 包、唐风美人背。

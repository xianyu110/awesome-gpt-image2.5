# Images 2.5 · Sketch 控形出片

## When
用户要控构图/布局，或说「不会画画也想出图」「先草图再精修」。

## Steps
1. 确认输出用途（封面 / 海报 / 产品图）和画幅（3:4、9:16、16:9）。
2. 在 ChatGPT Images 输入 `@Sketch`，用极简线稿标：主体位置、标题区、产品位、视线/光位（火柴人即可）。
3. 一句指令描述题材与风格，先用 **Flare** 出草稿验证构图。
4. 成片上用标注/评论改局部（「标题改成…」「加墨镜」），不要整段重抽。
5. 终稿切 **Sunburst**（或同画幅精修一轮）；需要多平台时用「调整尺寸」重排，勿简单裁切。
6. 交付：成图 + 可复制最终 prompt（含画幅与 must-keep 说明）。

## Notes
- Templates 适合海报起稿；Sketch 适合控形。
- 多轮改旧图易改错对象：一会话只盯一张，或新开对话。
- 参考案例：awesome-gpt-image2.5 分类「Sketch」。

# Images 2.5 · 像素精灵表→GIF

## When
用户要像素动画、战斗图、精灵表，或短动效种草素材。

## Steps
1. 上传角色/宠物图，声明「身份与服装唯一参考」。
2. 要求生成 **4×4（或 N×N）动作网格**，格子对齐、透明或纯色底、统一光源。
3. 用 Flare 快速出表；动作不对再标注单格重做。
4. 导出后切格、按序拼 GIF/短视频（剪映/FFmpeg 均可）。
5. 交付：精灵表原图 + GIF + 核心提示词（可换角色名）。

## Prompt 骨架
```text
上传图1作为角色身份与服装的唯一参考。
生成 4×4 像素风动作表，网格对齐，每格一个清晰动作，…
```
